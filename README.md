# Modulistica – Istituto Comprensivo di Almese

Pagina web per compilare i modelli dell'Istituto dal telefono o dal computer, firmarli con il dito e ottenere il PDF da scaricare o inviare alla scuola.

- I dati inseriti restano sul dispositivo di chi compila: la pagina non ha database e non invia dati a terzi.
- I modelli contengono solo campi vuoti: nessun dato personale è pubblicato qui.
- Il PDF compilato si invia alla casella dell'Istituto (moduli@comprensivoalmese.it) o alla segreteria.

Questo repository contiene solo la pagina, generata automaticamente: i file di lavoro non sono qui.
